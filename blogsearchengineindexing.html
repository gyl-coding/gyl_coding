博客收录到搜索引擎

博客建好、部署上线之后，最常见的疑问就是：“为什么我用搜索引擎搜不到我的文章？”

答案很简单：搜索引擎不会主动发现你的网站。它要先去”认识”你的站点，验证你确实是站长，然后才会派出爬虫来抓取。这个过程就是本文要讲的——把站点提交给 Google 和必应，让文章能被搜到。

本文记录的是 Hexo + GitHub Pages 子目录部署（https://xxx.github.io/xxx/）的完整接入过程，原理对其他博客框架同样适用。

前置准备：robots.txt 和 sitemap

提交之前，先确保站点根目录有这两个文件（Hexo 里放在 source/ 下即可，构建时会自动生成到站点里）：

robots.txt —— 告诉爬虫哪些能爬、以及 sitemap 在哪：

User-agent: *
Allow: /

Sitemap: https://你的用户名.github.io/你的仓库/sitemap.xml

sitemap.xml —— 站点所有页面的清单。Hexo 装 hexo-generator-sitemap 插件后执行 hexo g 会自动生成，不需要手写。

一、Google Search Console

1. 添加资源

打开 Google Search Console，点击 添加资源。

注意两点：

  • 选 “网址前缀”（URL prefix）类型，不要选”域名”类型。github.io 无法添加 DNS 验证记录，域名类型走不通。
  • 地址要填完整子目录：https://xxx.github.io/xxx/（带仓库名和末尾斜杠），而不是根域名。

2. 验证站点

推荐 HTML 文件方式：Google 会给你一个校验文件（比如 google123456789.html，内容是一行 google-site-verification: google123456789.html）。

放进 Hexo 的 source/ 目录时，务必在文件头部加 front-matter，否则 Hexo 会把它当文章渲染、包一层页面外壳导致校验失败：

---
layout: false
---
google-site-verification: google123456789.html

然后 hexo g + hexo d 发布，回到 Search Console 点”验证”。它会去抓 https://xxx.github.io/xxx/google123456789.html，返回 200 且内容正确即验证通过。

3. 提交 sitemap

验证通过后，左侧菜单 站点地图 → 输入 sitemap 地址提交：

https://xxx.github.io/xxx/sitemap.xml

最好填完整网址（相对路径 /sitemap.xml 有时会解析出错）。提交后看”已发现的网页”是否开始累加。

二、必应 Webmaster

1. 添加站点

打开 Bing Webmaster，用微软账号登录后添加站点。

可以直接用 “从 Google Search Console 导入” 把 Google 里已验证的站点一键导入（省去重新验证）。如果导入按钮不可用，就手动添加，验证方式选 XML 文件 / HTML 文件，同样放到 source/ 里带 layout: false 发布即可。

2. 提交 sitemap 和单篇加速

  • 站点左侧 站点地图 → 提交 https://xxx.github.io/xxx/sitemap.xml，看到”发现的 URL”数量就说明处理成功。
  • 想让某篇文章优先收录，用 URL 提交 功能单独提交文章链接（每站每天最多 10 条）。

三、踩坑记录

坑 1：sitemap 一直显示”无法抓取”

Google 的站点地图页显示 无法抓取、已发现 0，但浏览器打开 sitemap 明明正常。两个常见原因：

  1. 提交时机撞上构建窗口：刚部署完就提交，GitHub Pages 还在构建，抓取时返回 404。删掉重新提交即可，或等它自动重试（1~3 天）。
  2. sitemap 里有未来时间：如果某篇文章的 date 写到了未来，sitemap 里的 <lastmod> 就会是未来日期，Google 认为违反规范、卡住整个 sitemap。把文章日期改回真实日期重新发布即可。

坑 2：github.io 无法提交百度站长

百度站长平台不允许添加 github.io 这类共享主域（报”该主域可添加站点数量超过限制”），需要自定义域名才能接入。没有域名的只能先放弃百度。

坑 3：文章日期不要写未来

不止影响 sitemap。文章 date 写未来时间，Hexo 默认会生成，但会让搜索引擎、读者都困惑。date 就是发布时间，写真实日期。

四、如何验证收录

  • 搜索引擎里搜 site:你的域名，有结果即已收录（如 site:gyl-coding.github.io/gyl_coding/）。
  • 直接搜文章标题，能搜到你的博客链接说明已被索引。
  • 看站长后台数字：Google 的”已发现的网页”、必应的”发现的 URL”。

总结

  1. 先有 sitemap + robots.txt，再去做提交，事半功倍。
  2. Google 用”网址前缀”资源 + HTML 文件验证 + 提交 sitemap。
  3. 必应可以从 Google 一键导入，再用 URL 提交加速单篇。
  4. 收录是时间问题：新站通常 1~3 周 内陆续被索引，别天天刷新，隔几天看一次 site: 就行。
  5. github.io 共享主域接不了百度，想全渠道收录就买个自定义域名。
